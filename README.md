# VDarpan - Business Directory

A modern, responsive business directory website built with React.js, featuring JustDial-like functionality with VDarpan branding.

## 🌟 Features

- **Advanced Search**: Multi-field search with location and category filters
- **Business Listings**: Professional business cards with ratings and reviews
- **Category Browsing**: Visual category cards with high-quality images
- **Responsive Design**: Mobile-first approach that works on all devices
- **Modern UI/UX**: Glass morphism, gradients, and smooth animations
- **Contact Integration**: Direct phone calling and directions functionality

## 🚀 Live Demo

Visit the live website: [VDarpan Business Directory](https://your-app-name.onrender.com)

## 🛠️ Technologies Used

- **Frontend**: React.js 18, React Router DOM
- **Styling**: CSS3 with Flexbox/Grid, Custom animations
- **Icons**: Font Awesome 6
- **Images**: Unsplash API for high-quality business images
- **Deployment**: Render

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/vdarpan-directory.git
cd vdarpan-directory
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm test` - Launches the test runner
- `npm run eject` - Ejects from Create React App

## 🌐 Deployment

The application is deployed on Render with automatic deployments from the main branch.

### Deploy to Render

1. Push your code to GitHub
2. Connect your GitHub repository to Render
3. Set build command: `npm run build`
4. Set start command: `serve -s build`
5. Deploy!
